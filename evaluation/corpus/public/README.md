# Ankur Evaluation Corpus

This directory contains six team-authored evaluation materials plus one separate golden-demo source. The text and generated fixture files are released by Team Hotasha under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Attribution: **Team Hotasha, Ankur Evaluation Corpus, 2026**.

The materials are purpose-written, contain no learner data, and may be redistributed under the stated licence. Their educational prose is a bounded evaluation fixture, not professional safety or emergency advice.

`manifest.json` is authoritative for stable IDs, language/domain/input coverage, hashes, and review status. `golden-demo.expected.json` records the separate demo material’s team-authored semantic expectations without prescribing model wording. Its `manualVerificationStatus` remains `pending` until a human reviewer verifies that rendered/extracted pages match the authored references.
